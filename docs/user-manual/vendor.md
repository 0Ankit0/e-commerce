# Vendor Guide

## Vendor Pages

- Vendor Dashboard
- Products
- Inventory
- Orders
- Shipments
- Payouts

## Workflow: Complete Onboarding and KYC

1. Open Vendor Dashboard.
2. Review onboarding progress sections.
3. Fill pending profile/KYC fields.
4. Upload required documents when prompted.
5. Submit for review.
6. Monitor status updates in dashboard timeline sections.

## Workflow: Manage Catalog

1. Open Products.
2. Create or edit product entries.
3. Confirm listing details and pricing.
4. Save updates.
5. Re-open products list to verify changes.

## Workflow: Maintain Inventory

1. Open Inventory.
2. Update stock quantities by SKU/variant.
3. Save inventory changes.
4. Verify updated levels in inventory list.

## Workflow: Process Vendor Orders

1. Open Vendor Orders.
2. Filter by order status.
3. Open an order to review details.
4. Update status according to fulfillment step.
5. Confirm status update in list view.

## Workflow: Manage Shipments

1. Open Shipments.
2. Review shipment state and tracking details.
3. Trigger shipment-related actions (where available).
4. Verify state updates on refresh.

## Workflow: Handle Payouts

1. Open Payouts.
2. Review payout requests and status.
3. Submit request where eligible.
4. Verify request appears with correct amount/status.

## Success Checks

- Product and inventory edits persist after refresh.
- Order and shipment state transitions appear in lists.
- Payout requests and statuses are visible on Payouts page.
