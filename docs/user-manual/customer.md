# Customer Guide

## Customer Pages

- Dashboard
- Shop and product browsing
- Cart
- Checkout
- Orders
- Wishlist
- Notifications
- Profile
- Settings
- Finances
- Maps (if enabled)
- Tenants and Tokens (advanced, environment-specific)

## Workflow: Browse and Add to Cart

1. Open Shop.
2. Filter or search products.
3. Open product detail.
4. Select quantity/options.
5. Add item to cart.
6. Open Cart and verify item, quantity, and price.

## Workflow: Checkout and Place Order

1. Open Checkout from Cart.
2. Confirm address and shipping details.
3. Select payment method.
4. Review order summary.
5. Place order.
6. Open Orders and verify the new order appears.

## Workflow: Manage Wishlist

1. Open Wishlist.
2. Add or remove saved products.
3. Move a wishlist item to cart when ready.
4. Confirm item appears in Cart.

## Workflow: Track Notifications

1. Open Notifications page.
2. Use Unread only filter if needed.
3. Mark important items as read after action.
4. Delete obsolete notifications.

## Workflow: Update Account Preferences

1. Open Settings.
2. Update visible preferences.
3. Save changes.
4. Refresh once and confirm persisted state.

## Success Checks

- Orders and wishlist actions are reflected immediately in corresponding pages.
- Notification count decreases after read actions.
- Profile/settings changes remain after refresh.
