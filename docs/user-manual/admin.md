## Workflow: Monitor Operations Health

1. Open Admin Dashboard.
2. Review top-level marketplace KPIs.
3. Open Live Feed for recent cross-domain events.
4. Filter/scan for anomalies.
5. Jump to impacted module for deeper action.

## Workflow: Branch and Logistics Oversight

1. Open Branch Operations.
2. Review shipment and SLA cards.
3. Use drill-down filters for shipments and agents.
4. Trigger intervention actions when required.
5. Open Branch Dashboard for KPI snapshots and trends.

## Workflow: User and Access Administration

1. Open Users.
2. Search/select target user.
3. Verify role assignments.
4. Open RBAC to adjust access policies when needed.
5. Re-test affected route access with the target role.

## Workflow: Vendor Governance

1. Open Vendors.
2. Review onboarding and KYC statuses.
3. Approve/reject based on verification evidence.
4. Re-check Vendor dashboard and records for final status.

## Workflow: Delivery and Notification Analytics

1. Open Communications Delivery.
2. Review delivery rate, bounce/failure rates, and dead letters.
3. Open Notification Analytics for trends.
4. Investigate anomalies and retry/fix channels as needed.

## Workflow: Promotions and Campaign Planning

1. Open Promotions.
2. Review campaign lifecycle sections (draft, scheduled, active, archived).
3. Coordinate timing with catalog/content updates.
4. Validate visibility after campaign activation (when backend integration is enabled).

## Success Checks

- Live Feed loads without API errors.
- Branch pages show data and action hooks.
- Users/RBAC changes immediately affect route access.
- Promotions page is reachable and ready for campaign integration.
