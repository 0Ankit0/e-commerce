# Agent Guide

## Agent Pages

- Agent Dashboard
- Assignments
- History
- Branch Cockpit

## Workflow: Start Shift and Review Workload

1. Open Agent Dashboard.
2. Check assigned workload and status widgets.
3. Confirm availability and readiness for new tasks.

## Workflow: Execute Assignments

1. Open Assignments.
2. Filter to active tasks.
3. Open assignment details.
4. Update assignment state during each delivery step.
5. Confirm status reflected in assignment list.

## Workflow: Verify Delivery History

1. Open History.
2. Filter by date or outcome.
3. Validate completed and failed attempts.
4. Use records for reconciliation and issue follow-up.

## Workflow: Branch Cockpit Operations

1. Open Branch Cockpit.
2. Review inventory health and SLA indicators.
3. Review intervention queues (reassign/escalate/prioritize).
4. Use available action hooks when thresholds are breached.
5. Re-check metrics after intervention.

## Success Checks

- Assignment updates are reflected in both Assignments and History.
- Branch cockpit loads snapshot, alerts, and drilldown-backed metrics without errors.
- Notification updates appear in header and notifications center.
