# Common Basics

## Sign In

1. Open the sign-in page.
2. Enter username and password.
3. Submit and wait for redirect to your primary dashboard.
4. Use the user menu in the top-right to confirm identity and role context.

## Global Header Features

- Theme selector: switch visual theme.
- Language button: choose active language.
- Notifications bell: view recent alerts and mark items as read.
- User menu: open account actions and role-specific navigation.

## Notifications Workflow

1. Click Notifications in the header.
2. Review latest items in the popover.
3. Choose Mark read for specific items or Mark all read.
4. Select View all notifications for the full notifications page.

## Profile and Settings

1. Open Profile to review account information.
2. Open Settings to manage preferences.
3. Save changes and verify confirmation state.

## Troubleshooting

- If a page looks stale, refresh once to trigger latest data fetch.
- If a role page is denied, verify your role assignment in Admin > Users.
- If maps do not render, verify environment feature flags for map providers.
