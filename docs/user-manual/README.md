# User Manual

This guide set explains how each role should use Northstar Market day-to-day.

## Audience Guides

- [Common Basics](./common.md)
- [Customer Guide](./customer.md)
- [Vendor Guide](./vendor.md)
- [Admin Guide](./admin.md)
- [Agent Guide](./agent.md)

## Recommended Reading Order

1. Start with Common Basics.
2. Read the guide for your primary role.
3. If you hold multiple roles, read each relevant guide and switch portal context before each workflow.

## Notes

- Route access depends on role permissions.
- Some modules can show empty states if no domain data exists yet (for example, no orders or no shipments).
- Maps may be disabled per environment configuration.
